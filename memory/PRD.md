# Novaxs E-Commerce Platform - PRD

## Overview
Novaxs is a fully automated hands-free e-commerce platform with PayPal Business payments and CJ Dropshipping fulfillment.

## What's Implemented ✅
- **Frontend**: React + Tailwind CSS + Shadcn UI
- **Backend**: FastAPI + MongoDB
- **PayPal Business API**: LIVE - Real payment processing
- **CJ Dropshipping API**: Connected - Automated order fulfillment
- **Categories**: Women's/Men's Fashion, Pet Supplies, Electronics, Health & Beauty, Outdoor Sports
- **Features**: Product catalog, cart, checkout, user auth, order tracking

## Automated Pipeline
1. Customer pays via PayPal → 2. Order auto-sent to CJ → 3. CJ ships to customer → 4. Profit in your PayPal

## User Personas
- **Shoppers**: Browse products, add to cart, checkout with PayPal
- **Admin**: Monitor orders, track fulfillment status

## Tech Stack
- Frontend: React 19, Tailwind CSS, Shadcn UI
- Backend: FastAPI, Motor (async MongoDB)
- Database: MongoDB
- Payments: PayPal Business API (LIVE)
- Fulfillment: CJ Dropshipping API
